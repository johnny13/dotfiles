# YABAI SHORTCUTS

| **Action** | **Shortcut** | **What It Does** |
|---|---|---|
| **Focus Window** | Option + H / J / K / L | Move active focus Left (H), Down (J), Up (K), Right (L) |
| **Swap Window** | Option + Shift + H / J / K / L | Swap current window position with neighbor in that direction |
| **Toggle Float** | Option + Space | Un-tile current window (make it float) or re-tile it |
| **Toggle Fullscreen** | Option + F | Zoom the current window to fullscreen |
| **Fix/Reload Yabai** | Option + Shift + R | **Restarts the yabai daemon** to fix any layout glitches |
